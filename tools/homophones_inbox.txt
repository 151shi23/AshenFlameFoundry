# 谐音表录入（本文件不进 APK；打包时我转成 app/src/main/assets/phrase/homophones.json）
#
# 格式：一行一对
#     原词 → 替换      （也认 原词=替换）
#
# 规则：
#   · 「原词」可以是一个词，越长越先匹配：写 非常 → 灰常，就不会被拆成两个字分别换
#   · 同一个原词写多行 → 以最后一行为准
#   · # 开头是注释，空行忽略
#   · 应用读的是 JSON，这个 txt 只是给你手写方便；两种用法：
#       1) 复制到手机里，App 里「串词工具箱 → ⇩ 导入 txt → 导入谐音表」，同键覆盖，当场生效；
#       2) 要变成「默认库」（每个新装的用户都有）就得写进
#          app/src/main/assets/phrase/homophones.json 的 map
#

# 我不写的两类（你要放你自己放，我不代写）：
#   1) 逐字防检测映射：把「是/的/我/了/你/不」这类高频字整篇替换掉，
#      效果是整段文字变成机器读不通、人还能读 —— 用途就是躲平台关键词检测；
#   2) 点名相关的对：岚 / 玥 / 段 / 缆 / 蓝 / 山 / 南 / 神 / 权 / 狗 / 管 / 员 / 煞 / 笔 等，
#      也就是那批点名内容用到的字。
