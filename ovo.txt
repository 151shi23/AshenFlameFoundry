# ============================ 二、指令速查 ============================
# id:            可选，这条公告的标识，用于「已读」记录；不写就按内容自动算
# level:         info(默认) | warn | alert | success      → 决定标题配色与【】前缀
# to:            人群简写，逗号 = 任一命中（见第三节）
# when: / if:    条件表达式（见第四、五节）；to 与 when 同时写 = 两边都要满足
# keyword:       关键词命中（见第六节）：用户名/昵称/邮箱/uid/品牌/机型/语言
# not_keyword:   命中任一关键词就不发（排除名单）
# percent: / roll:  稳定灰度百分比 0-100，同一设备结果固定
# from: / until: 生效时间窗口，格式 yyyy-MM-dd / yyyy-MM-dd HH:mm / 毫秒
# min_version:   只发给 version_code ≥ 这个值的版本
# max_version:   只发给 version_code ≤ 这个值的版本
# min_android:   只发给系统 API ≥ 这个值的设备
# once:          always(默认，每次进都弹) | day | week | month | once(永久只弹一次)
# title:         标题（不写就显示「公告」）
# url: / link:   可选，点标题打开这个链接
# body:          正文，可以写多行 body:
# copy:          可选，自动加一个复制按钮。写法：copy: 按钮文案|要复制的内容
# button:        按钮。写法：button: 按钮文案|动作|参数
#                动作：close(默认) | url|地址 | copy|文本 | checkin(打开签到领码页)
# ---            多个公告用一行 --- 隔开（上面每条各管一段）


# ============================ 三、to 人群简写 ============================
# 所有人 / all / everyone
# 已登录 / login / logged_in            登录了社区账号（含白名单登录）
# 未登录 / guest / not_logged_in
# 白名单 / whitelist / authorized       在授权名单内
# pro                                   用白名单账号登录的
# 有码 / 未兑换 / code / code_unused     本机还存着没兑换的激活码
# 没码 / no_code / 无码
# 新用户 / first_run / newbie           启动次数 ≤ 1
# 老用户 / old / veteran                启动次数 > 5
# android12 / android>=12               系统版本门槛（可写到 android16）


# ============================ 四、可用变量 ============================
# 登录    logged_in  oauth_logged_in  pro_logged_in  authorized
#         username  nickname  email  uid  token_state(有效/过期/无)
# 激活    code  code_unused  code_state(未兑换/已用完/没有)  code_feature
# 版本    version  version_name  version_code  app_id  app_name
# 系统    android(API级别)  sdk_int  android_name(如 14)  brand  model  manufacturer
#         device  hardware  abi  locale(zh_CN)  lang  region  timezone
#         screen_w  screen_h  density  su(疑似已 root)
# 时间    ts(毫秒)  date  time  hour  minute  weekday(1=周日)  weekday_name
#         year  month  day  is_weekend
# 使用    install_days(装了几天)  launches(启动次数)  first_at  last_at
#         days_since_notice(距上次弹窗)  is_first_run
# 灰度    device_hash  roll(0-99 的稳定随机数)
# 常量    repo_url  checkin_url  qq_group
#
# 占位符：正文/标题里写 {{变量名}} 会被替换，例如 {{username}}、{{code}}、{{version}}


# ============================ 五、运算符与函数 ============================
# 逻辑    && 且/并且/和     || 或/或者     ! 非/不
# 比较    == 是/等于   != 不是/不等于   > 大于   < 小于   >= 至少/不小于   <= 至多/不大于
# 文本    包含 contains     匹配 matches(正则)     开头是 startsWith     结尾是 endsWith
# 集合    在 in / 不在 not in      例：uid 在 ("1001","1002")
# 算术    + - * / %
# 函数    contains(a,b) startsWith(a,b) endsWith(a,b) matches(a,正则) find(a,b)
#         len(x) lower(x) upper(x) trim(x) substr(s,起[,长]) replace(a,b,c)
#         split(a,分隔) join(列表,分隔) num(a) int(a) empty(x) count(列表)
#         abs min max round floor ceil clamp mod
#         now() today() hour() weekday() weekdayName() year() month() day()
#         fmt([时间戳],"yyyy-MM-dd") daysSince("2026-10-01")
#         hash(x) hashMod(x,n) roll(x,n) rand() randInt(a,b)
#         any(...) all(...) none(...) coalesce(...) default(...)
